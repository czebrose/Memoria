# Online play: the field body of each playable character (Memoria Step 2 / M3).
# Install as <mod folder>/StreamingAssets/Data/Online/CharacterBodies.txt
#
# One character per line:   characterId Name: Model m, Head h, Action animId, Action animId, ...
#   characterId  the party character id (CharacterParameters.csv: 0 Zidane, 1 Vivi, 2 Garnet, 3 Steiner, 4 Freya,
#                5 Quina, 6 Eiko, 7 Amarant, 8 Cinna, 9 Marcus, 10 Blank, 11 Beatrix in vanilla)
#   Model        the model the body is created with; more "Model" entries = other models the field scripts use for
#                this character (recognised as this character, never created)
#   Head         SetModel's head height (dialog box height)
#   Actions      every character should have these 14 (missing ones play Stand):
#                Stand, Walk, Run, TurnLeft, TurnRight,
#                KneelDown, Kneeling, KneelUp, OpenDoor,
#                LadderOn, LadderClimb, LadderOffTop, LadderOnDown, LadderOffBottom
#                Extra actions may be added with any name.
# With this file, only the bodies it declares exist (the mod's characters aren't the vanilla ones). Without it,
# vanilla characters have built-in bodies (Stand/Walk/Run/TurnLeft/TurnRight only).
# A character with no body: a guest playing them keeps the host character's body (logged).
#
# When a guest plays another character, the field's player entry (created with the host's character's body,
# Clove) is created with the guest's body, and each of Clove's animations is replaced by the guest's animation
# for the same action.

# The sequel's party (CharacterDefaultName in DictionaryPatch.txt). Bodies as the mod's field scripts draw them today.
