# Types for mod lookups Update-ModLookups.ps1 can't place by itself: the object comes from a method parameter, a
# method call, or an expression such as UIManager.Battle. Hand-kept; the updater lists any new one it needs.
#
# <mod file> <member name> <type it's looked up on>
#   type: a full type name, or Type::member (that member's type), as in mod-lookups.txt
#   '-':  the type isn't in Assembly-CSharp (e.g. a HashSet's Clear): not checked
# Lookups on objects read through these (GetValue, GetMember(obj, ...), foreach) are then followed automatically.
